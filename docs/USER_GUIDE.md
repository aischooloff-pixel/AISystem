# Руководство пользователя — для Юлии

Написано простым языком. Здесь всё, что нужно для ежедневной работы
с вашим цифровым отделом продаж.

---

## 1. Как работает система — общая картина за 5 минут

У вас появился AI-помощник в Telegram. Он делает четыре вещи:

1. **Встречает людей**, которые пишут вашему боту: представляется
   AI-помощником (никогда — вами), спрашивает о ситуации, задаёт
   несколько вопросов.
2. **Определяет, кто перед ним**: человек с реальным запросом, «просто
   читатель» или нецелевое обращение (медицина, магия, юристы — не к нам).
3. **Передаёт вам готовых клиентов**: когда человек хочет записаться или
   созрел — вам приходит карточка со всей историей. Дальше работаете вы,
   бот замолкает.
4. **Следит за комментариями** в канале: замечает потенциальных клиентов,
   предлагает вариант ответа — публикует только после вашего «Опубликовать».

Всё, что бот узнал о людях, хранится в Airtable (ваша CRM) — откройте
airtable.com в любой момент и посмотрите.

Главное правило системы: **AI не заменяет вас. Он готовит человека
к качественному живому разговору с вами.** Все важные решения — за вами.

## 2. Статусы клиентов и как их читать

| Статус | Значение | Что делает бот |
|--------|----------|----------------|
| 🔥 `hot` — горячий | Хочет записаться, спросил цену, готов платить | Немедленно передаёт вам |
| 🟡 `warm` — тёплый | Описывает проблему, интересуется методом | Отвечает, мягко предлагает диагностику |
| 🔵 `cold` — холодный | Читает, но запроса нет | Не продаёт; ждёт, приглашает к материалам |
| ⚪ `non_target` — нецелевой | Не наш запрос (врач/юрист/магия), агрессия | Вежливо завершает разговор |
| `in_progress` — в работе | Вы уже работаете с человеком | Молчит, всё пересылает вам |
| `client` — клиент | Действующий клиент | Молчит, всё пересылает вам |

Статус ставится не «по ощущению», а по наблюдаемым признакам — они всегда
записаны в поле «Основание статуса». Если AI не уверен (уверенность ниже
85%) — решение он не принимает, а передаёт вам с пометкой «Требуется
экспертная оценка».

Ваше решение всегда главнее: если вы сменили статус вручную, автоматика
его не переопределит.

## 3. Карточка клиента: что означает каждое поле

Когда клиент передаётся вам, приходит карточка:

- **Заголовок** — статус и уверенность AI (или «Требуется экспертная оценка»);
- **👤 Имя (@username)** — кто; **📍 Источник** — откуда пришёл;
- **🔗 Первое касание · всего касаний** — как давно и как активно;
- **ЗАПРОС** — краткое нейтральное резюме его ситуации;
- **ЧТО УЖЕ ПРОБОВАЛ(А) / ЧЕГО ХОЧЕТ** — его ответы на вопросы;
- **КЛЮЧЕВЫЕ ЦИТАТЫ** — дословные фразы человека (не пересказ);
- **Осознанность / Готовность / Срочность** — три оценки по шкале
  высокая-средняя-низкая;
- **ОСНОВАНИЕ СТАТУСА** — наблюдаемые признаки, по которым принято решение;
- **ИСТОРИЯ КАСАНИЙ** — хронология: комментарии, переходы, диалоги;
- **РЕКОМЕНДАЦИЯ** — предлагаемый следующий шаг (решение — ваше).

## 4. Кнопки под карточкой

| Кнопка | Что произойдёт |
|--------|----------------|
| **✅ Беру** | Клиент закреплён за вами, бот молчит, клиенту: «Юлия скоро свяжется с вами лично», в задачах появится «Связаться с …» |
| **🔄 Прогрев** | Клиент возвращается боту со статусом «тёплый» — бот продолжит бережное общение |
| **⛔ Нецелевой** | Бот вежливо попрощается, общение завершено |
| **⏸ Пауза** | Бот замолкает, клиенту ничего не отправляется (пауза на подумать) |

После нажатия кнопки исчезают, на карточке появляется отметка с датой.

## 5. Команды в Telegram (пишутся боту)

| Команда | Пример | Что делает |
|---------|--------|-----------|
| `/admin` | `/admin` | Список всех команд |
| `/info` | `/info 123456789` | Полная карточка клиента |
| `/timeline` | `/timeline 123456789` | История касаний |
| `/status` | `/status 123456789 warm` | Сменить статус вручную |
| `/pause` / `/resume` | `/pause 123456789` | Остановить / включить бота для клиента |
| `/assign_me` / `/assign_ai` | `/assign_me 123456789` | Взять на себя / вернуть боту |
| `/stop` | `/stop 123456789` | Завершить взаимодействие |
| `/note` | `/note 123456789 просила позвонить в среду` | Добавить заметку |
| `/stats` | `/stats` | Сколько клиентов в каких статусах |
| `/tasks` | `/tasks` | Открытые задачи |
| `/hot` | `/hot` | Список горячих лидов |
| `/reload_knowledge` | `/reload_knowledge` | Перечитать базу знаний (после правок) |
| `/health` | `/health` | Проверка: всё ли работает |

`123456789` — это Telegram ID клиента, он есть в каждой карточке.

## 6. Работа с комментариями

Когда кто-то оставляет содержательный комментарий под постом канала,
вам приходит уведомление: кто, под каким постом, что написал, насколько
похож на потенциального клиента — и **предложенный ответ**.

- **✅ Опубликовать** — ответ публикуется в комментариях **от имени бота**
  (не от вашего имени);
- **✏️ Изменить** — пришлите свой вариант следующим сообщением, он и будет
  опубликован;
- **⏭ Пропустить** — ничего не публикуется.

Без вашего решения не публикуется ничего и никогда.

## 7. Дашборд в Airtable: где что смотреть

Откройте базу в Airtable. Таблицы:

- **Contacts** — все люди: статусы, источники, история переписки, заметки;
- **Touches** — каждое касание (комментарий, сообщение, передача) — из них
  складывается хронология;
- **Comments** — все комментарии с анализом и статусом ответа;
- **Posts** — посты канала: сколько комментариев и потенциальных клиентов
  принёс каждый;
- **Tasks** — задачи-напоминания для вас.

Рекомендуемые представления (views) — создаются один раз, инструкция:
в таблице Contacts нажмите «Grid view → Create new view», задайте фильтр:

| View | Как настроить |
|------|---------------|
| Все лиды | сортировка по created_at ↓ |
| По статусам | группировка по status |
| По источникам | группировка по source |
| 🔥 Горячие | фильтр status = hot |
| На Юлии | фильтр assigned_to = yulia |
| Требуют действия | фильтр next_action_date ≤ сегодня |
| Без ответа | фильтр result = no_response |
| Открытые задачи | таблица Tasks, фильтр status = open |
| Комментарии на утверждение | таблица Comments, фильтр reply_status = pending |

## 8. Еженедельный отчёт: как читать метрики

Каждый понедельник в 10:00 приходит отчёт:

- **Продажи** — новые обращения, диалоги, передачи вам, вошедшие в работу;
- **Источники** — откуда приходят люди (что усиливать);
- **Контент** — сколько комментариев, какой пост привёл больше всего
  потенциальных клиентов (какие темы работают);
- **AI** — средняя уверенность и сколько раз AI передал решение вам;
- **Конверсии** — как люди двигаются по воронке;
- **Требует внимания** — открытые задачи и неутверждённые ответы.

Если данных за неделю не было, отчёт честно так и напишет — нули
не рисуются.

## 9. Как добавить материал в базу знаний

База знаний — папка `bot/knowledge/` в проекте: обычные текстовые файлы
(brand.md — о бренде, products.md — продукты и цены, faq.md — вопросы-ответы
и т.д.).

1. Пришлите Ивану новый текст (или отредактируйте файл на сервере).
2. Файл кладётся в папку — код менять не нужно.
3. Напишите боту `/reload_knowledge` — бот перечитает базу.

Важно: бот отвечает ТОЛЬКО на основе этих файлов. Изменились цены —
сначала обновите products.md.

## 10. Что делать, если что-то пошло не так

Короткая версия (полная — в файле RECOVERY.md):

- Бот молчит → `/health`. Если не отвечает и на это — перезапуск:
  `sudo systemctl restart geikina-bot` (см. RECOVERY.md, п. 1).
- Бот говорит странное → остановите его: `sudo systemctl stop geikina-bot`
  и напишите Ивану. Сообщения клиентов не потеряются.
- Данные клиентов всегда в безопасности в Airtable + еженедельная
  резервная копия (подтверждение приходит вам в воскресенье).

## 11. Границы системы: что бот НЕ делает и почему

- **Не выдаёт себя за вас** — всегда представляется AI-помощником
  (принцип прозрачности).
- **Не проводит диагностику и не интерпретирует** ситуацию клиента —
  экспертные решения принадлежат вам.
- **Не давит и не продаёт**: не торгуется, не даёт скидок, не создаёт
  срочность. Предлагает — не навязывает.
- **Не обещает результат** — запрещённые формулировки перехватываются
  автоматически, даже если модель их сгенерирует.
- **Не публикует ничего от вашего имени** и ничего — без вашего утверждения.
- **Не отвечает на темы вне компетенции**: медицина, право, инвестиции,
  политика, религия — вежливо переадресует к профильным специалистам.
- **Останавливается по одной кнопке** — любой автоматический сценарий
  можно выключить (⏸ Пауза, /pause, /stop).
