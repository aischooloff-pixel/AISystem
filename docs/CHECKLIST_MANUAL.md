## 4. Что посмотреть в Airtable

- **Contacts** — один клиент = одна строка. Проверьте `conversation_history`:
  там должна быть вся переписка, включая ответы бота.
- **Touches** — история не пустая, у касаний осмысленные описания.
- **Posts** — один пост = одна строка, `comments_count` совпадает
  с фактическим числом комментариев.
