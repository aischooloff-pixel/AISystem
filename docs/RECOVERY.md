# Что делать, если что-то пошло не так

Инструкция для Юлии. Написана простым языком — технические знания не нужны.
Для всех команд: подключитесь к серверу так, как показывал Иван (программа
PuTTY или Терминал, адрес и пароль — в переданном вам файле с доступами).

---

## 1. Бот не отвечает клиентам

1. Подключитесь к серверу и выполните команду:

       sudo systemctl restart geikina-bot

2. Подождите 30 секунд и напишите боту в Telegram команду `/health`.
3. Если все строки со значком ✅ — всё в порядке, бот работает.
4. Если бот по-прежнему молчит — напишите Ивану и приложите фото/скриншот
   экрана с тем, что показала команда.

## 2. Бот отвечает неправильно или странно

Например: обещает результат, называет неверные цены, ведёт себя не по
правилам бренда.

1. Немедленно остановите бота:

       sudo systemctl stop geikina-bot

   Клиенты перестанут получать ответы — это лучше, чем неправильные ответы.
2. Напишите Ивану, приложите скриншот странного ответа.
3. Пока бот остановлен, новые сообщения клиентов НЕ пропадают:
   Telegram сохранит их и доставит после включения.

## 3. Откатить неудачное обновление

Если после обновления бот стал работать хуже:

1. Посмотрите список последних версий:

       cd /home/yulia/geikina-bot && git log --oneline -10

2. Каждая строка — версия. Верхняя — текущая. Выберите ту, что была
   до обновления (обычно вторая сверху), скопируйте её код
   (первые 7 символов строки), и выполните:

       git checkout КОД_ВЕРСИИ
       sudo systemctl restart geikina-bot

3. Проверьте `/health` в Telegram. Сообщите Ивану, что откатились.

## 4. Полное восстановление с нуля (10–15 минут)

Если сервер пришлось пересоздать:

1. Найдите свежий бэкап в папке `/home/yulia/backups/`
   (файл вида `backup_20260725_030000.tar.gz`) — или скачанную копию.
2. Распакуйте:

       cd /home/yulia
       tar -xzf backups/backup_ДАТА.tar.gz
       mv ДАТА/code geikina-bot

3. Установите зависимости:

       cd geikina-bot
       python3.11 -m venv .venv
       .venv/bin/pip install -r requirements.txt

4. Верните настройки и базу знаний из бэкапа:

       cp ../ДАТА/.env .env
       cp -r ../ДАТА/knowledge/* bot/knowledge/

5. Запустите:

       sudo systemctl start geikina-bot

6. Проверьте `/health` и напишите боту `/start` с другого аккаунта.

## 5. Про данные клиентов

Все данные клиентов хранятся в Airtable — это облачный сервис, при поломке
сервера они НЕ теряются. Достаточно открыть airtable.com и войти в базу.

Дополнительно каждое воскресенье в 03:00 система сама делает полную
резервную копию (включая выгрузку всех таблиц Airtable в файлы) и присылает
вам подтверждение в Telegram. Если подтверждение в воскресенье не пришло —
сообщите Ивану.

## Полезные команды в Telegram (пишутся боту)

| Команда | Что делает |
|---------|-----------|
| `/health` | Проверка всех систем |
| `/stats` | Сколько клиентов и в каких статусах |
| `/pause 123456789` | Остановить автоматику для клиента |
| `/admin` | Полный список команд |
